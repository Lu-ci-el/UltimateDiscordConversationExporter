# UltimateDiscordConversationExporter — UDCE 0.0.1

**BetterDiscordで使う、Discord会話保存プラグインです。**

追加ログイン・Token入力なし。  
会話をローカル保存し、画像はHTMLで表示します。必要な添付はブラウザ画面から選択して保存できます。

保存したHTMLひとつの中で、**会話を読む → カレンダーで日付を絞る → 添付を見る → 必要なファイルを選んで保存する**、まで操作できます。別の添付ブラウザを開く必要はありません。

[English manual](README_EN.md) · [GitHub](https://github.com/Lu-ci-el/UltimateDiscordConversationExporter) · [変更履歴](CHANGELOG.md) · [検証範囲](tests/README.md)

> Windows・Discord・BetterDiscord実機での、この統合版の最終確認は未完了です。検証済みの範囲と未確認事項は末尾に記載しています。

## 1. インストール・入れ替え

1. BetterDiscordを導入したDiscordデスクトップ版を用意します。これは通常のWeb版Discordへ入れるブラウザ拡張ではありません。
2. Discordの **ユーザー設定 → BetterDiscord → Plugins → Pluginsフォルダを開く** を選びます。
3. `UltimateDiscordConversationExporter.plugin.js` をそのフォルダへ入れます。
4. Plugins一覧で **UltimateDiscordConversationExporter** を有効にします。
5. 保存したいDM・グループDM・テキストチャンネルを開き、**Export** を押します。

**Pluginsへ入れるのはJSファイルひとつだけです。** READMEやtestsをPluginsへ入れる必要はありません。追加ライブラリや起動用CMDの実行も不要です。

旧版から入れ替える場合は、取得中の処理を一時停止し、旧プラグインをOFFにしてから同名JSを置換します。旧名のExporterを含め、同種プラグインを重複してONにしないでください。**既存の出力フォルダと `.udce_state` は削除しません。**

BetterDiscord側の導入については[公式Quick Start](https://docs.betterdiscord.app/plugins/introduction/quick-start)も参照してください。

## 2. 最初の書き出し

Export画面で開始・終了日時、出力先、出力形式を指定します。最初は短い期間で、本文・日付・画像表示を確認してください。

| 項目 | 操作・意味 |
| --- | --- |
| 開始日時 | ここから保存する日時。空欄なら取得可能な最古側が対象です。 |
| `00:00:00` | **開始欄で選択している日付を変えず、時刻だけ0時にします。** 今日へ変更するボタンではありません。 |
| 終了日時 | ここまで保存する日時。空欄でも開始時点の最新を上限として固定し、取得中の新着を無限に追いません。 |
| Message URL / ID | 入力した側では日時より優先されます。指定メッセージを境界に含めます。 |
| 出力フォルダ | 完全な初回値は `C:\Discord_Exports`。手入力または **📁 参照...** からWindows標準のフォルダ選択画面で変更できます。選んだ場所は次回も記憶します。管理用の再開データもこの配下に保存します。 |
| 出力形式 | `TXT＋ブラウザHTML` / `HTMLのみ` / `TXTのみ`。初期値は両方です。 |
| ページ要求間隔 | 初期値1000ms。高速取得やアカウントの安全を保証する値ではありません。 |

例：開始欄の日付を `2026/01/01` に変更し、横の **00:00:00** を押すと、`2026/01/01 00:00:00` からの指定になります。Message ID欄が残っているとそちらが優先されるので、日時で指定する場合はID欄を空にしてください。

出力先の **📁 参照...** を押すと、Windowsのネイティブなフォルダ選択画面が開きます。ファイルではなくフォルダだけを選びます。キャンセルした場合は現在の保存先を変更しません。以前に `D:\...` や `G:\...` を設定している場合は、その保存済み設定を維持し、更新しただけで `C:\Discord_Exports` へ戻しません。

新規Jobは開始境界から新しい方向へ取得します。旧Jobは保存時の取得方向を維持して再開します。手動でDiscord画面をスクロールし続ける必要はありません。

### 取得画面

**期間進捗**は指定した期間を日単位でどこまで進んだか、です。処理時間の予測ではありません。発言の密度によって1日を取得する時間は変わります。

`一時停止` は再開位置を残します。`停止して部分出力` は取得済み分を出力します。`保存済み／再開` からJobを確認できます。処理が終わる前のPARTIALや未確認を、完全取得と同一には扱いません。

左下の **フォルダを開く** は、利用可能なDiscordネイティブ機能で保存場所を表示します。環境にその機能がない場合は保存先のコピーへ切り替え、コピーだったことを通知します。勝手にフォルダを開く機能ではありません。

## 3. 出力されるもの

通常の出力では、選んだ形式に応じて次を作ります。

```text
会話名_日時_識別子_files/
  00_ALL_MESSAGES_BY_DATE.txt   日付区切りの会話全文（UTF-8）
  01_BROWSER_BY_DATE.html       会話・添付・ダウンロードの統合画面
  media/                       動画・音声・その他など、明示してローカル保存し成功した添付のみ
  export_info.json             出力状態・整合性情報
```

読み物として必要なのはTXTとHTMLです。`export_info.json` は検証用メタデータです。通常出力をさらにZIPへ自動圧縮する機能はありません。配布用ZIPと、会話の出力フォルダは別物です。

ローカル添付を使う場合は、**HTMLとmediaフォルダを同じ位置関係のまま**保存してください。新規Jobでは画像本体をExport時に自動保存しません。旧Jobや動画・音声・その他のローカル添付がある場合だけ `media/` を使います。

パスワード保護をONにした場合は、HTMLと `02_ARCHIVE.udce` が中心になります。保護を無意味にしないため、書き出し時に平文TXTを同時生成しません。復号後に必要な範囲をTXTとして保存できます。

## 4. カレンダー・日付目次

左に月カレンダーと月別の日付目次を表示します。会話がある日に印と件数が付きます。

**日付を押すと、開いているモードをその日に絞ります。** 会話モードなら会話、添付モードなら添付、ダウンロードモードならファイル一覧が連動します。

選んだ日をもう一度押すと解除します。**日付解除**ボタンでは、日付選択と上部の開始・終了日の絞り込みを外せます。**リセット**は検索・話者・種類なども含めて解除します。再読み込みは不要です。

日付目次の検索は `05/26` などで絞れます。カレンダーの左右ボタンは表示月を変えるだけで、勝手に新しい日付を選びません。

## 5. 会話モード

本文・添付名・話者・Message IDの検索、投稿者、開始・終了日、添付あり・画像あり・返信・Botの絞り込みを利用できます。本文は翻訳せず、保存された文章と改行を表示します。

メッセージは日付見出しで区切り、1ページ100件を表示します。**前へ／次へはページ上部と下部の両方**にあり、下側から次ページへ進むと新しいページの先頭へ戻ります。返信の参照先がアーカイブ内にあればその位置へ移動でき、**前の表示へ**で戻れます。`Discord ↗` は許可された元リンクが残る場合だけ表示します。

**ここから／ここまで**で会話範囲を選び、コピーまたはTXT保存できます。範囲未選択なら検索結果が対象です。**範囲解除**で検索結果全体へ戻ります。TXT保存も確認してから開始します。

## 6. 画像・添付モード

画像は会話内へ直接表示します。添付モードでは、画像のプレビューとファイル情報を一覧で確認できます。`ALL / 画像 / 動画 / 音声 / その他`、ファイル名、拡張子、投稿者で絞れます。

拡張子欄に `zip dat xml lua` と入れると、そのいずれかの拡張子だけを表示します。大文字小文字は区別せず、先頭のドットは省略できます。上部の共通検索・日付・話者条件とも組み合わさります。

| 表示 | 意味 |
| --- | --- |
| ローカル保存済み | 書き出し時の保存成功情報とローカルパスがあります。実体を移動・削除すると読み込めなくなります。 |
| URLあり | 保存されたDiscord CDN URLがあります。現在の到達可否やダウンロード成功を保証する表示ではありません。 |
| URLなし | 取得データにない、またはプライバシー処理等でURLが残っていません。勝手に復元しません。 |

**新規Jobでは画像本体をExport時に自動保存しません。** 添付情報と許可されたDiscord CDN URLをHTMLへ残し、そのURLを `<img>` 表示に使います。旧Jobにローカル保存済み画像がある場合だけローカル実体を優先します。「オンライン画像」をOFFにすると外部プレビューを止めます。通常の自分用HTMLでは初期ON、保護・匿名化されたアーカイブでは初期OFFです。本文の検索だけなら通信しません。

ファイルの `開く` と `元メッセージ` は明示的な操作です。ファイルを見たいだけで一括ダウンロードが始まることはありません。保存時の内部エラーコードは必要なときに **保存時の詳細**で確認できます。

## 7. ダウンロードモード

カードではなく、**名前 / 種類 / サイズ / 日付 / 投稿者 / 状態 / 操作**の一覧です。列見出しは一覧の上端へ固定され、ファイル一覧だけをスクロールできます。

| 操作 | 結果 |
| --- | --- |
| 未選択の行をクリック | その1件を選択します。 |
| 選択済みの行をもう一度クリック | その行を解除します。 |
| Ctrl＋クリック | 他の選択を残して追加・解除します。 |
| Shift＋クリック | 最初に選択した行から押した行までを範囲選択します。 |
| Ctrl＋Shift＋クリック | 既存選択を残して範囲を追加します。 |
| Ctrl＋A | 現在の絞り込み結果を全選択します。入力欄で文字を編集中なら通常の文字選択です。 |
| Esc | 選択を解除します。 |
| チェックボックス | その1件を追加・解除します。 |

**選択しただけでは保存も別タブ表示もしません。** 次のいずれかを押して、件数と概算容量の確認ダイアログで了承した後に開始します。

| ボタン | 対象 |
| --- | --- |
| 選択をダウンロード | チェック・行選択した添付。フィルター変更で表示外になった選択も含みます。表示外の選択数を表示します。 |
| 表示中を一括ダウンロード | 現在のフィルター結果全体です。スクロールで見えていない行も含みます。 |
| 全添付を一括ダウンロード | 日付・拡張子等のフィルターを無視した全添付です。 |

URLも保存済みファイルもない項目は対象外として確認に含めます。同名ファイルはブラウザ側で名前を調整する場合があります。取得中は中止できます。失敗しても勝手に画像タブを大量に開きません。

**保存先はブラウザのダウンロード設定に従います。** Exportで指定したフォルダへ自動保存する機能ではありません。ブラウザから「複数ファイルのダウンロード」許可を求められた場合は、内容を確認して判断してください。

結果の **ブラウザへ渡しました** は、保存処理をブラウザに依頼した状態です。ディスクへの保存完了はブラウザのダウンロード一覧で確認します。外部取得は1ファイル256 MiBを上限にし、CORS・リンク期限・通信エラー等は失敗として表示します。[ブラウザのdownload属性](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/a#download)と[CORS](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/CORS)にはブラウザ側の制約があります。

## 8. 伏字・匿名化・パスワード保護

「秘密情報を全部一括」でしか選べない構造ではありません。必要な項目を個別に選べます。

| 分類 | 個別設定 |
| --- | --- |
| 名前・識別情報 | 名前・表示名、User ID、Message ID・返信ID、Mention・Channel・Role ID、添付名、URL |
| 秘密情報候補 | パスワード、API Key・Secret、Token、Authorization・Bearer、Private Key、Discord Webhook、メールアドレス、カード番号候補 |
| 独自指定 | 任意文字列、正規表現 |

IDを隠す場合は一貫した仮名を使い、返信関係や同一人物の対応を維持します。元のIDがリンクに残る場合は、その関連リンクも隠します。**名前を伏せる設定だけで本文中のあらゆる人名が消えるわけではありません。** ラベルのないパスワード等も完全自動判定ではありません。必要な語は独自指定し、共有前に出力を確認してください。

画像内の文字・顔や、添付ファイル内部を自動的に塗り潰す機能ではありません。プライバシー設定を使っても、添付本体の共有は別に確認が必要です。

**本文中のパスワード候補を伏せる設定**と、**出力をパスワードで暗号化する設定**は別です。保護出力はHTMLを開き、対応する `.udce` を選んでパスワードを入力します。再ロックで表示と復号データの参照を解除します。復号後のTXT・添付の保存は平文になるため、確認が出ます。パスワードを忘れた場合の解除機能はありません。

## 9. 再開と既存データ

対応形式の保存済みJobを読み、元の範囲・取得方向・プライバシー方針を保って再開します。現在のチェック状態で旧Jobの方針を勝手に上書きしません。古い情報が既に伏字になっている場合、元に戻すこともできません。

`保存済み／再開` には、再開、取得済み分の出力、失敗添付の再試行、検査などの操作があります。**最新HTMLへ出し直すだけなら、既存Jobの「取得済み分の出力」を使えます。** これは未取得メッセージの追加取得ではありません。旧HTML自体が自動更新されるわけではありません。

`.udce_state` は復旧用データです。出力の仮名化設定を使っていても内部に照合用のID等を保持するため、**共有用の添付に含めないでください。**

## 10. 画像の表示と保存

新規Jobでは **「画像本体をローカル保存」設定を廃止**しています。画像添付のファイル名・種類・サイズ・Discord CDN URLは「添付ファイル情報」がONなら記録し、HTMLではそのURLを使って表示します。

必要な画像は **添付モード / ダウンロードモードから選択してブラウザ保存**してください。選択しただけでは保存を開始せず、ダウンロードボタンを押した後に件数・概算容量の確認を出します。保存先はブラウザ設定に従います。

Discordの添付CDN URLには有効期限があります。URLだけの保存を永続的なオフライン保存とは扱わないでください。期限切れ・CORS・通信エラーの場合、HTMLの表示やブラウザダウンロードも失敗することがあります。静的HTMLはDiscordへ再ログインして署名を更新する機能を持ちません。[Discord公式：Signed Attachment CDN URLs](https://docs.discord.com/developers/reference#signed-attachment-cdn-urls)

動画・音声・その他添付のローカル保存設定、および旧Jobに既に記録されたメディア保存状態は互換性のため残しています。旧Jobでは過去の `MEDIA_RANGE_MISMATCH` 等が表示される場合がありますが、新規Jobは画像本体の自動保存タスクを作りません。

### よくある状態

| 状態・症状 | 確認すること |
| --- | --- |
| 日付を戻せない | 同じ日をもう一度押すか日付解除。他の検索条件も解除するならリセット。 |
| 画像が表示されない | 「オンライン画像」、CDN URLの期限、通信状態を確認。 |
| URLは開くがブラウザダウンロードだけ失敗 | CORS・通信・期限・容量・ブラウザの複数DL許可を確認。 |
| `NOT_REQUESTED` | その添付本体のExport時ローカル保存を要求していない状態。画像のHTML表示可否とは別です。 |
| `HISTORY_RECEIPT_UNVERIFIED` | 履歴応答を確認できていないため一時停止。完全取得とはみなしません。 |

## 11. 検証と配布について

今回の差分では、Node構文、0.0.1版表示、新規Jobで画像ローカル保存が常にOFFになること、画像URLが添付情報として残ること、生成HTMLに上下ページャー・オンライン画像表示・選択ダウンロード経路が残ることを確認しています。親0.0.1の過去検証記録は参考として残しますが、今回の環境で旧テスト一式を再実行したとは扱いません。

Windows・Discord・BetterDiscord実機、実CDN・CORS、複数ダウンロード許可、ネイティブなローカルHTMLからの暗号化Viewerは別の検証です。今回の環境では `file://` 遷移が管理ポリシーによりブロックされ、ネイティブViewer確認は未確認として残しています。暗号処理と既存Jobの復号・再開はNode側で検証しています。詳細は [tests/RESULTS.json](tests/RESULTS.json)。

非公式のBetterDiscord用プラグインです。DiscordやBetterDiscordによる承認・アカウント処分回避・無欠損を保証しません。閲覧権限のある会話に使用し、他人の会話・添付を公開する前に権利とプライバシーを確認してください。配布ZIPに私用の会話ログは含めません。
